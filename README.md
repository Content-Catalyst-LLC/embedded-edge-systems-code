# Embedded and Edge Systems Code

This repository supports the Embedded and Edge Systems knowledge series.

It includes practical examples for:

- SQL telemetry schemas and quality checks
- Embedded C firmware-style anomaly monitoring
- TinyML inference scaffolds for constrained devices
- PYNQ edge-acceleration workflows
- Python telemetry validation and feature engineering
- R sensor reliability reporting
- Device metadata, telemetry contracts, calibration manifests, and governance notes

The repository is designed for educational, reproducible, local-first examples.
