# HIL and Digital-Twin Notes

Research-grade CPS validation should progress through multiple readiness stages:

1. Model simulation
2. Software-in-the-loop
3. Processor-in-the-loop
4. Hardware-in-the-loop
5. Subsystem integration
6. System integration
7. Field pilot
8. Monitored operation

A digital twin is useful when it preserves explicit links between model assumptions, measured behavior, uncertainty, timing, and operational evidence.

Hardware-in-the-loop validation is especially important because timing, bus behavior, driver behavior, and watchdog logic often determine whether an embedded CPS works in the real world.
