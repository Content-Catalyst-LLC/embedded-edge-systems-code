# HDL Companion Code

This folder contains HDL scaffolding for CPS hardware/software co-design.

The examples include:

- `adc_sampler` for sampled data capture
- `quadrature_decoder` for encoder feedback
- `pwm_generator` for actuator command output
- `timing_monitor` for deadline-violation signaling
- `safety_gate` for hardware-level command gating
- constraints placeholder for board-specific adaptation
