# Cyber-Physical Systems and Hardware Integration

This companion directory supports the article **“Cyber-Physical Systems and Hardware Integration.”**

The goal is to make the article useful to engineers, researchers, and advanced technical readers by pairing the systems explanation with executable cyber-physical simulation, interface-contract validation, timing analysis, uncertainty budgets, traceability, hardware-in-the-loop scaffolding, digital-twin scaffolding, and hardware/software co-design examples.

The workflows model cyber-physical systems as composed evidence systems involving:

- physical-process simulation
- sensor observation and calibration metadata
- state estimation
- candidate command generation
- runtime assurance and safety filtering
- actuator saturation and physical consequence
- timing budgets and deadline validity
- uncertainty budgets
- interface contracts
- bus and protocol profiles
- requirements traceability matrices
- digital-twin and HIL readiness checks
- CPS telemetry and event schemas
- TinyML local anomaly detection
- PYNQ/FPGA signal preprocessing
- HDL timing, PWM, encoder, ADC, and safety-gate scaffolds
- C/C++/Rust/Go/MicroPython systems examples

This directory is not production CPS firmware. It is a research-grade companion scaffold intended to make the article's engineering concepts executable, inspectable, and extensible.
