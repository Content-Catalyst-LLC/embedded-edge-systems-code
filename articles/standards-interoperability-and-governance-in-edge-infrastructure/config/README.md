# Configuration and Governance Manifests

This folder contains YAML and JSON configuration files for:

**Standards, Interoperability, and Governance in Edge Infrastructure**

These files represent the metadata layer of the companion workflow. They document device profiles, telemetry schemas, deployment rules, lifecycle policy, update policy, and article-level reproducibility metadata.

In embedded and edge systems, YAML and JSON manifests are not decorative. They are the structured evidence layer that makes devices, updates, models, overlays, firmware, telemetry, and governance assumptions machine-readable.
