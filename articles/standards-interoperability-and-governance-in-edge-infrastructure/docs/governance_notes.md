# Governance Notes

For embedded and edge systems, interoperability governance should include:

- A device and gateway inventory
- Supported protocol and API profiles
- Schema and data model versions
- Firmware versions and update state
- Vendor support status
- Security baseline evidence
- Credential and identity practices
- Ownership and decision-right records
- Deprecation and exception handling
- Exportable governance evidence

A system that cannot produce these records may be technically functional but operationally difficult to govern.
