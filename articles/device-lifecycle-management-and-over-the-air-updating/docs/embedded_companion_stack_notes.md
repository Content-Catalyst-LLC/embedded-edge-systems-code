# Embedded Companion Stack Notes

This article directory uses the expanded Embedded & Edge Systems companion-code standard.

## Core analytics and reproducibility

- Python for advanced workflow logic and reproducible analysis
- R for statistical reporting and descriptive summaries
- SQL for schemas, governance records, and queryable evidence
- Jupyter notebooks for exploratory and educational workflows

## Systems programming

- C for constrained embedded logic and low-level device examples
- C++ for gateways, interfaces, streaming pipelines, and firmware-style abstractions
- Rust for safe systems validation, lifecycle policies, and reliability-oriented tooling
- Go for lightweight services, telemetry gateways, and operational utilities
- Bash for repeatable local workflow execution

## Embedded and edge deployment

- MicroPython for microcontroller telemetry and edge prototypes
- TinyML for constrained on-device inference and model lifecycle scaffolding
- PYNQ for FPGA-backed acceleration and overlay lifecycle governance
- HDL for hardware/software co-design and real-time stream-processing scaffolds
- YAML and JSON for structured device, deployment, lifecycle, telemetry, update, model, and overlay metadata
