# Mathematical Lens: Privacy Risk Reduction Through Local Transformation

A simple local-processing privacy model can be written as:

\[
R_{\mathrm{privacy}} = w_cC + w_iI + w_rR + w_lL + w_sS - w_mM - w_tT - w_eE
\]

Where:

- \(C\): collection breadth
- \(I\): identifiability
- \(R\): retention duration
- \(L\): linkability across contexts
- \(S\): upstream sharing scope
- \(M\): minimisation strength
- \(T\): local transformation strength
- \(E\): ephemeral processing strength

The model is not a universal privacy metric. It is a structured way to reason about how edge systems reduce risk when raw data are minimised, transformed locally, retained briefly, and disclosed selectively.
