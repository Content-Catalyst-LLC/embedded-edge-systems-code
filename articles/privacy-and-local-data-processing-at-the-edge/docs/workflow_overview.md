# Workflow Overview

This companion directory demonstrates how privacy-preserving edge design can be represented as code and evidence.

The workflow begins with sample edge observations, applies local minimisation and redaction, calculates privacy risk scores, produces reporting summaries, stores governance records, and provides embedded/system examples that show how the same privacy concepts can be applied on constrained devices, gateways, TinyML runtimes, and accelerated edge nodes.

The core question is not whether data are processed locally. It is whether local processing changes the data lifecycle in ways that reduce collection, identifiability, retention, linkage, and unnecessary disclosure.
