# Privacy and Local Data Processing at the Edge

This companion directory supports the Sustainable Catalyst article **“Privacy and Local Data Processing at the Edge.”**

The workflows model privacy-preserving edge design as a lifecycle of collection, minimisation, local transformation, selective disclosure, retention, identity-linkage control, and governance evidence.

The examples include:

- Python workflows for privacy risk scoring and local data minimisation
- R workflows for privacy reporting across edge fleets
- SQL schemas for local data-processing records, retention policy, and disclosure evidence
- C and C++ examples for constrained local filtering and redaction
- Rust validation for retention and disclosure policy
- Go examples for a local privacy gateway service
- MicroPython examples for privacy-aware sensor telemetry
- TinyML local inference stubs for event-only reporting
- PYNQ overlay metadata for accelerated local filtering
- HDL stream filters for privacy-preserving signal reduction
- YAML/JSON manifests for device, telemetry, lifecycle, retention, model, overlay, and governance metadata
