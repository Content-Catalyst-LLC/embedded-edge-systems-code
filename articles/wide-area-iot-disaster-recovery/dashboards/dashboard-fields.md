# Disaster IoT Dashboard Fields

A useful disaster IoT dashboard should make uncertainty and silence visible.

Recommended fields:

- device ID
- location code
- protocol
- hazard type
- latest sensor value
- alert state
- latest timestamp
- battery percentage
- signal quality
- gateway or backhaul route
- device health status
- firmware version
- maintenance flag
- last successful transmission
- missed heartbeat count
- local responsible institution
- response status
