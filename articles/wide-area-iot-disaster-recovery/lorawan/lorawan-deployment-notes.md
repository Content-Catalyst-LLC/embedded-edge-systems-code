# LoRaWAN Deployment Notes

LoRaWAN can be valuable for disaster recovery when communities, municipalities, NGOs, researchers, utilities, or public agencies need local long-range connectivity that does not depend entirely on commercial cellular coverage.

Key planning needs:

- gateway elevation and antenna placement
- link-budget testing
- terrain and vegetation review
- gateway power backup
- backhaul redundancy
- duty-cycle and payload discipline
- device key management
- local maintenance plan
- field drills before disaster season
