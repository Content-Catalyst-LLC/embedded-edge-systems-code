# Satellite IoT Notes

Satellite IoT can provide continuity where terrestrial infrastructure is absent or disrupted.

Patterns:

1. Gateway backhaul for local LoRaWAN or sensor networks.
2. Direct-to-satellite IoT devices for isolated assets.

Key planning needs:

- antenna placement
- sky visibility
- power budget
- message frequency limits
- subscription cost
- latency expectations
- integration with local alerts
- fallback when satellite windows are unavailable
