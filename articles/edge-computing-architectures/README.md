# Edge Computing Architectures

This companion directory supports the article **Edge Computing Architectures**.

It models edge computing architecture as responsibility placement across endpoint devices, embedded runtimes, gateways, local edge nodes, regional edge layers, cloud services, management planes, trust layers, observability layers, and runtime-assurance layers.

Engineering focus:

- workload placement
- latency and bandwidth budgets
- offline continuity
- runtime assurance
- fail-safe and fail-operational boundaries
- trust boundaries
- secure boot and attestation
- SBOM/provenance concepts
- fleet inventory
- deployment and rollback
- observability
- incident reconstruction
