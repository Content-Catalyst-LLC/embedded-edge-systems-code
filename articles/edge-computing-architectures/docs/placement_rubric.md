# Placement Rubric

1. Hard real-time response: prefer endpoint device or embedded runtime.
2. Protocol translation and child-device aggregation: prefer gateway.
3. Site-level analytics and operator visibility: prefer local edge.
4. Low-latency multi-site coordination: prefer regional edge.
5. Fleet-wide training, identity, archival storage, and policy: prefer cloud.
6. Cloud outage continuity: prefer device, gateway, or local edge.
7. Raw data locality: prefer device, gateway, or local edge.
8. Rapid governance iteration: weigh cloud control against local latency and continuity.
9. Runtime assurance: require watchdogs, heartbeats, degraded modes, and recovery sequencing.
10. Trust: require identity, secure boot, attestation, signed workloads, provenance, and signed telemetry.
