# Edge AI and On-Device Machine Learning

This companion directory supports the article **“Edge AI and On-Device Machine Learning.”**

The goal is to make the article useful to engineers, researchers, and advanced technical readers by pairing the systems explanation with executable model-budget checks, quantization-impact analysis, runtime and accelerator validation, confidence/fallback simulation, fleet monitoring, model lifecycle governance, TinyML scaffolds, PYNQ/FPGA validation, HDL stream components, and multi-language embedded/edge examples.

The workflows model edge AI as local interpretation infrastructure involving:

- device capability profiles
- sensor and feature schemas
- model budgets
- quantization profiles
- runtime manifests
- backend validation reports
- CPU / accelerator numerical parity checks
- latency and memory SLOs
- confidence thresholds and fallback logic
- drift proxies and feature-summary monitoring
- model-version skew monitoring
- inference event schemas
- deployment readiness gates
- signed model and rollback metadata
- MicroPython sensor-window prototypes
- TinyML model manifests and classifier stubs
- PYNQ/FPGA feature-preprocessing validation
- HDL stream timestamping, feature windows, inference triggers, and telemetry framing
- C/C++/Rust/Go systems examples
- Python and R analysis workflows

This directory is not production embedded AI infrastructure. It is an engineering-grade companion scaffold intended to make the article's architecture concepts executable, inspectable, and extensible.
