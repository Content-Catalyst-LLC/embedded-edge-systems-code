# Embedded Control Systems for Real-Time Physical Regulation

This companion directory supports the article **“Embedded Control Systems for Real-Time Physical Regulation.”**

The goal is to make the article useful to engineers, researchers, and advanced technical readers by pairing the systems explanation with executable embedded-control, timing, safety-filtering, and hardware/software co-design scaffolding.

The workflows model embedded control systems as closed-loop cyber-physical regulation involving:

- discrete-time plant models
- PID control
- state-space dynamics
- estimator residuals
- timing budgets
- deadline validity
- loop jitter
- actuator saturation
- command filtering
- anti-windup
- supervisory state machines
- DC motor speed-control examples
- control-loop telemetry
- safety envelopes
- failure containment
- TinyML loop anomaly detection
- PYNQ/FPGA preprocessing and validation
- HDL timing, PWM, encoder, and safety-gate scaffolds
- C/C++/Rust/Go/MicroPython systems examples

This directory is not production embedded-control firmware. It is a research-grade companion scaffold intended to make the article's engineering concepts executable, inspectable, and extensible.
