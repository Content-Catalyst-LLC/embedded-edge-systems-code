# Autonomous Systems and Edge Intelligence

This companion directory supports the article **“Autonomous Systems and Edge Intelligence.”**

The goal is to make the article useful to engineers, researchers, and advanced technical readers by pairing the systems explanation with executable autonomy, runtime assurance, monitoring, and embedded/edge scaffolding.

The workflows model autonomous edge systems as bounded decision systems involving:

- partial observation
- belief-state updates
- decision policies
- autonomy authority levels
- runtime assurance
- safety filtering
- fallback behavior
- latency budgets
- compute budgets
- drift monitoring
- autonomy event logs
- human intervention signals
- TinyML local inference scaffolds
- PYNQ/FPGA stream preprocessing
- HDL timing/safety gates
- C/C++/Rust/Go/MicroPython systems examples

This directory is not production autonomy software. It is a research-grade companion scaffold intended to make the article's engineering concepts executable, inspectable, and extensible.
