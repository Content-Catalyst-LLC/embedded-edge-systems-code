# Workflow Overview

1. Load fault-model, watchdog, recovery, safe-state, and telemetry manifests.
2. Simulate fault events across transient, intermittent, permanent, cascading, and common-cause classes.
3. Estimate detection coverage, recovery coverage, degraded-service time, and effective availability.
4. Summarize fleet-level reset and diagnostic behavior in R.
5. Store SQL schemas for reset causes, fault events, recovery evidence, and lifecycle actions.
6. Provide embedded systems scaffolds for watchdog supervision, recovery state machines, telemetry, validation, and hardware-assisted monitoring.
