# Reliability and Fault Tolerance in Embedded Devices

This companion directory supports the article **Reliability and Fault Tolerance in Embedded Devices**.

It treats embedded dependability as controlled failure: fault modeling, detection coverage, watchdog supervision, containment, recovery hierarchy, safe-state behavior, persistent-state integrity, field diagnostics, lifecycle response, and fleet-level evidence.

Engineering focus:

- faults, errors, failures, and propagation paths
- watchdog policies tied to meaningful system health
- recovery hierarchy and reset semantics
- degraded modes and safe-state behavior
- brownout and persistent-state validation
- fault-injection simulation
- fleet reliability reporting
- reset-cause and diagnostic telemetry
- systems-code scaffolding in C, C++, Rust, Go, MicroPython, TinyML, PYNQ, and HDL
