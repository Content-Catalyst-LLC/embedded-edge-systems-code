# Workflow Overview

1. Load candidate MCU/SoC platform data, device requirements, peripheral manifests, memory budgets, and lifecycle requirements.
2. Estimate compute utilization, memory margin, bandwidth margin, daily energy, peripheral coverage, and security/lifecycle support.
3. Generate Python outputs for silicon fit, platform risk, power estimates, memory constraints, and peripheral coverage.
4. Generate R outputs for platform portfolio comparison and device-class fit.
5. Store SQL schemas for platform requirements, peripheral evidence, memory budgets, power domains, security capabilities, lifecycle policies, and telemetry.
6. Provide systems-code scaffolds for capability contracts, fit evaluators, manifest validation, portfolio aggregation, PYNQ/FPGA-oriented SoC examples, and HDL platform blocks.
