# HDL Companion Code

This folder contains HDL scaffolding for edge analytics hardware/software co-design.

The examples include:

- `stream_timestamper` for acquisition-time preservation
- `feature_window_counter` for bounded window formation
- `feature_accumulator` for local feature accumulation
- `event_trigger` for feature-ready and event-threshold signaling
- `telemetry_framer` for version-aware analytics telemetry
