# HDL Companion Code

This folder contains HDL scaffolding for gateway and aggregation hardware/software co-design.

The examples include:

- `stream_timestamper` for acquisition-time preservation
- `buffer_watermark_monitor` for backlog and uplink pressure
- `sync_pulse_generator` for coordination timing
- `telemetry_framer` for model/policy/version-aware telemetry framing
