# Security in Embedded and Edge Systems

This companion directory supports the article **“Security in Embedded and Edge Systems.”**

The workflows model embedded and edge security as a cross-layer trust problem: hardware roots of trust, boot integrity, firmware resilience, device identity, communications boundaries, runtime isolation, update security, monitoring, recovery, lifecycle support, and supply-chain evidence.

The examples include:

- Python workflow for embedded security readiness and risk scoring
- R workflow for fleet security posture and lifecycle reporting
- SQL schema for device security profiles, firmware records, credentials, events, and recovery evidence
- C and C++ examples for local trust-state checks and gateway security policy
- Rust lifecycle/security policy validator
- Go security telemetry gateway example
- MicroPython trust-state telemetry prototype
- TinyML model-integrity and fallback manifest
- PYNQ overlay trust and compatibility validation
- HDL stream/security gate scaffolds
- Bash scripts for repeatable validation and workflow execution
- YAML/JSON manifests for boot policy, runtime policy, network boundaries, lifecycle policy, and security event schemas
