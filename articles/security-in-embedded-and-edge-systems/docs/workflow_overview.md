# Workflow Overview

This companion directory demonstrates how embedded and edge security can be represented as code, configuration, and evidence.

The workflow begins with device security metadata, calculates security-readiness scores in Python, summarizes fleet posture in R, stores security evidence in SQL, and provides systems-level examples showing how trust-state checks, update policy, credential validation, TinyML model integrity, PYNQ overlay validation, and HDL stream gates can be represented across the stack.
