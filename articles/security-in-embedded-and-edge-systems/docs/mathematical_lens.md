# Mathematical Lens: Security Readiness as Trust Capacity

A simple embedded and edge security readiness model can be written as:

\[
S_{\mathrm{edge}} = w_hH + w_bB + w_iI + w_uU + w_rR + w_mM - w_eE - w_dD
\]

Where:

- \(H\): hardware trust maturity
- \(B\): boot and firmware integrity
- \(I\): identity and credential strength
- \(U\): update and recovery readiness
- \(R\): runtime isolation
- \(M\): monitoring maturity
- \(E\): exposure
- \(D\): lifecycle drift

The model is not a proof of security. It is a structured engineering review tool for comparing devices, gateways, sites, support states, and trust assumptions.
